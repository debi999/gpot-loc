# G-POT 翻译器 · 测试用例

> 版本 v4.0 · 2026-10-09 · 按 UI 规格书 FR-35~FR-49 编号组织。
> 旧回归资产的继承映射见 §3 —— **继承用例的断言语义不变，只改挂载点**。

## 1. 用例规范

- 编号：`TC-<FR号>-<两位序号>`，如 `TC-FR36-01`。
- 每条用例三要素：前置 / 步骤 / 预期。预期必须可观察（UI 状态、文件字节、返回码），禁止"看起来正常"。
- 环境隔离约定（沿旧库）：跨机路径走 `ST_GAME_DIR` / `ST_TRUTH_REPO` / `ST_GUI_DIR`；
  找不到被测物 SKIP 且 exit 0；会改写真实 `server_config.ini` 的用例必须 snapshot/restore 保护。
- 输出铁律：所有被 `run_tests.py` 收编的脚本入口必须
  `sys.stdout/stderr.reconfigure(encoding='utf-8', errors='replace')`，且打印 `合计: N 项` 汇总行。
