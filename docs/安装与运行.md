# G-POT 翻译器 · 安装与运行（v0.6.0）

## 方式一：打包 exe（推荐给不装 Python 的机器）

### 打包（开发者在 I 盘做）

```bash
cd I:\AIcoding\gpot-loc
python tools\build_exe.py
```

产物落在 **`F:\erogame\G-POT\dist\G-POT翻译器\`**，整个文件夹拷走即可脱机运行。

### 使用（使用者）

1. 把 `G-POT翻译器` 整个文件夹复制到任意位置（路径含中文/空格都没关系）。
2. 双击 `G-POT翻译器.exe`。
3. 首次运行会自动打开无边框窗口。若双击没反应，看日志：
   `%TEMP%\gpot-run.log`。

> **工具缓存在哪**：下载的注入工具包会存在**程序所在文件夹**的 `toolcache\`
> 里，不在你的游戏目录。想离线部署，可以提前把包放进这个文件夹。
> 想换台机器、给多款游戏共用，把 `toolcache\` 一起拷过去就行。

## 方式二：源码跑（开发/调试）

```bash
cd I:\AIcoding\gpot-loc
pip install -r requirements.txt        # 只依赖 pywebview
python src\main.py                     # 无边框窗口
python src\main.py --open-browser      # 用系统浏览器打开
python src\main.py --no-gui            # 只起 API 服务（测试用）
python src\main.py --port 9000         # 指定端口（默认 8731）
```

或者直接双击仓库根目录的两个启动器：

| 启动器 | 行为 |
|---|---|
| `启动 G-POT 翻译器.bat` | 挑一个装了 pywebview 的 Python（没有就现场装），无黑窗启动 GUI |
| `启动 G-POT 翻译器(浏览器版).bat` | 不需要 pywebview，只起服务 + 系统浏览器 |

两个 bat 都会自动跳过 WorkBuddy 托管沙箱和 WindowsApps 的 store 桩
（那些 `python.exe` 是假桩，跑不了东西）。

## 运行环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11（边缘缩放用 Win32 `WM_NCHITTEST`，其它平台自动降级） |
| Python（源码跑） | 3.11+ |
| WebView2 | Windows 11 自带；Win10 需装一次（微软官方 Evergreen） |
| 联网 | 仅首次下载注入工具包时需要；之后可离线 |

## 快捷键

| 键 | 作用 |
|---|---|
| `Alt+1` ~ `Alt+7` | 跳到第 1 ~ 7 步 |
| `Alt+D` | 切换明暗主题 |
| `Ctrl+F` | 跳到校对页搜索框 |
| `Ctrl+Shift+S` | 保存并应用到游戏 |
| `Esc` | 关闭最上层弹窗 |
| 拖窗口四边/四角 | 缩放窗口 |

焦点在输入框里时，除 `Esc` 外快捷键一律让位（打字不会误跳步）。

## 排障

| 症状 | 查哪 |
|---|---|
| 双击没反应 | `%TEMP%\gpot-run.log` |
| 边缘拖不动窗口 | 同上，看有没有 `[edge-resize]` 段（有记录说明降级了） |
| 端口被占 | `python src\main.py --port 9000` 换一个 |
| 「需要密钥的提供方」点了获取没反应 | 那是必填校验 —— 先填 API Key 再点（设计如此，不是卡死） |

## 红线

打包/运行都**不改游戏本体文件**——只在「保存并应用」时写入词典与白名单，
其余步骤全程只读。
