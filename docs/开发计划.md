## 技术栈决策矩阵（M1 输入）

| 路线 | 真 WinUI 3 | 保 Python 内核与回归 | 相对成本 | 主要风险 |
|---|---|---|---|---|
| D tkinter 重排版面 | 否 | 全保 | 最低 | 达不到 Fluent 观感 |
| C Python + WebView2 仿 Fluent | 否（观感接近） | 全保 | 低 | 新增第三方依赖；大表性能需实测 |
| B C# WinUI 3 壳 + Python 内核 | 是 | 全保 | 中高 | 双语言双构建；沙箱无法自验编译；包体 ~100MB |
| A C# 全量重写 | 是 | **全丢** | 最高 | 等同重做项目 —— **已否决**（2026-10-09） |

**M1 验收口径**（哪条路线过线用哪条）：
- 14,679 行表格滚动/搜索/筛选流畅（交互响应 ≤200ms）
- 长任务进度推送与取消可用（翻译一跑几十分钟，不能假死）
- 构建可脚本化复现，产物能脱机运行
- 迭代节奏可接受（改一处到看到效果 ≤5 分钟）

## 源码迁移清单（M2，从旧库 `indie-game-translator`）

迁移纪律：**只搬家不改逻辑**；每迁一个模块跑一次 fast 回归。

| 旧位置 | 去向 | 说明 |
|---|---|---|
| `gui/StarmakerTranslator.py` | 拆分为内核 API + 弃用旧 UI | 业务方法全部保留；`_build_ui` 等旧版面代码不迁 |
| `gui/{TranslationStore,Translator,batch_fast,engine_detector,kit_catalog,kit_installer,rpgmaker_engine,lang_detector,ui_theme,check_assets}.py`（含内嵌于主程序的等价物） | `core/` | 唯一真源随迁 |
| `gui/_pathsetup.py` | 根目录 | 启动引导 |
| `gui/test_*.py`（10 脚本） | `tests/` | 见测试用例.md §3 映射 |
| `run_tests.py` / `hooks/` / `.github/` | 原样 | fast/full/commit 三档与 CI 保留 |
| `docs/`（旧说明书/优化方案） | **不迁** | 冻结在旧库；新文档以本库为准 |
| `toolcache/` | 不迁（.gitignore） | 运行时产物 |

## 风险登记

| 风险 | 缓解 |
|---|---|
| 沙箱无法运行 `dotnet`（安全策略） | 若选 B：构建命令全部脚本化，由老板本机一键执行；M1 先验证这条链路 |
| WindowsAppSDK ~200MB 首次联网 | 提前告知；或改用已缓存方案（C/D 无此依赖） |
| 迁移期间双库并存产生漂移 | 旧库即刻冻结（只读）；迁移 PR 一次性完成，不留跨库长期分支 |
| UI 层与内核耦合回归 | M2 纪律：迁移 commit 与改 UI commit 严格分离 |
