# G-POT Loc · 本地测试指南（可测试原型 v0.3）

> 本指南给你一份「双击就能测」的版本。原型跑得通七步完整流程，但**业务逻辑是 STUB（模拟）**——
> 它的作用是让你验收**界面、导航锁、按引擎变脸、信息密度、整体观感**，而不是真去翻译某个游戏。

---

## 一、这是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 七步流水线的完整可交互 UI | 真实引擎识别（目前固定返回 Unity） |
| 导航锁 / 解锁链真实生效 | 真实提取（统计数字来自旧库，但非真扫游戏） |
| 第 5 步按引擎自动变脸（Unity / RPG Maker / 无方案） | 真实翻译（进度是模拟的，约 6–16 秒跑满） |
| 前端通过 `fetch` 调本地 API，零业务规则在前端 | 真实注入（apply 只改内存状态，不碰游戏文件） |
| 三层解耦架构（core / api / ui）落地 | 1.4 万条大表性能实测（第 4 步现为 20 行样本） |

真实逻辑迁移（M2）只换 `src/gpot/core/` 里的 `TODO(M2)` 接缝，不动 API 契约与前端。

---

## 二、环境要求

- **Python 3.11+**（建议 3.11，与旧版 v3.x 一致；3.13 也验证过）
- **pip**
- **Windows 10 / 11**
  - 「窗口版」需系统自带 WebView2 运行时（Win10/11 通常自带）
  - 「浏览器版」免此要求，用系统默认浏览器即可

---

## 三、启动（二选一，都双击即可）

仓库根目录已放好两个 bat：

| 文件 | 用途 | 何时用 |
|---|---|---|
| **`启动 G-POT 翻译器(浏览器版).bat`** | 起本地服务 + 自动开系统浏览器 | **推荐首选**，最稳，不依赖 WebView2 运行时 |
| `启动 G-POT 翻译器.bat` | 起 WebView2 原生窗口 | 想看接近成品的 Fluent 观感时用 |

首次运行会自动 `pip install -r requirements.txt`（仅 `pywebview` 一个依赖），稍慢。

命令行等价方式：

```bat
cd src
pip install -r requirements.txt
python main.py                 :: WebView2 窗口
python main.py --open-browser  :: 系统浏览器
python main.py --no-gui        :: 只起 API（调试用，另开浏览器手输 http://127.0.0.1:8731/）
python main.py --port 9000     :: 换端口（默认 8731）
```

## 四、七步走查清单（建议逐条核对）

| 步 | 操作 | 预期表现 |
|---|---|---|
| **0 配置** | 选 `ollama`（默认），点「连接并继续」 | 状态变「已连通」，自动跳第 1 步 |
| **1 游戏** | 在输入框粘贴任意路径，如 `F:\erogame\Starmaker_Story\Starmaker Story(1.8e)` → 点「选择并继续」 | 显示游戏名 + 已有 14,679 条译文，自动跳第 2 步 |
| **2 引擎** | 点「识别引擎」 | 显示引擎名 / 置信度 / 硬证据 / 管线三连（从哪来→写到哪→怎么生效）；点「部署注入工具」显示三件套（已验证）并自动跳第 3 步 |
| **3 提取** | 点「开始扫描」 | 显示 新增 / 已存在 / 护栏拦截(8,045) / 总数，自动跳第 4 步 |
| **4 翻译** | 点「翻译未译条目」 | 进度条跑到 100%（约 6–16s），右下「继续·应用到游戏」解锁 |
| **5 落盘** | 顶部切换 Unity / RPG Maker MV / 无方案；点主按钮 | 三种形态各异（见下）；应用后自动跳第 6 步 |
| **6 验证** | —— | 提示文字随引擎变；3 项检查「通过」；可「回到第 4 步修改」 |

## 五、三个最值得你重点看的验证点

1. **导航锁（刚性规则）**：左侧未解锁的步骤是灰色、不可点。把流程走一半刷新页面（或点重置），
   已过的步骤能自由回跳，未来的步骤点不动——这证明 `core/store.py` 的锁真实生效，不是页面假装的。
2. **第 5 步按引擎变脸**（这是界面设计的核心）：
   - **Unity**：显示「游戏本体不动 / 写入词典 / 改动仅 2 处」，**没有**还原按钮
   - **RPG Maker MV**：显示字段白名单 + 「不翻」黑名单 + **「还原原文」按钮**（因为会改真实文件）
   - **无方案引擎**：显示「为什么做不了」的诚实清单 + 替代建议，**没有**伪装入口
3. **信息密度（NFR-12）**：每页说明文字已压到一行导语 + 卡片至多一行副标题，没有提案说辞。

## 六、已知限制（诚实告知，避免误判）

- **全部业务逻辑为 STUB**：`detect_engine` 固定返回 Unity；`extract` 返回固定统计（数字取自旧库真实数据）；
  `translate` 是模拟进度；`providers.test_connection` 仅 ollama 模拟连通。
- **第 4 步表格是 20 行样本**，不是真实 1.4 万条。大表滚动/搜索/分页性能在 M2 接真数据后实测。
- **文件夹选择为手动粘贴路径**：WebView2 内无原生文件对话框，M2 接 pywebview 文件对话框后改为点选。
- 重置演示：第 6 步或左侧底部有「重置」可反复走。

## 七、解耦自检（给我看架构没烂）

```bat
cd src
python tests/test_pipeline.py
```

8 项内核测试**只 `import gpot.core`**，证明内核可脱离 UI 独立运行、可无浏览器回归。
铁律：**core 永不 import api/ui；api 只 import core；前端只 fetch。**

## 八、常见问题

| 现象 | 解决 |
|---|---|
| 端口被占用（提示地址已用） | 用 `--port 9000` 换一个 |
| WebView2 窗口空白/报错 | 系统缺运行时，改用「浏览器版」bat |
| 中文乱码 | bat 已 `chcp 65001`；若仍乱码检查系统区域设置 |
| `python` 不是命令 | 把 Python 加进 PATH，或把 bat 里的 `python` 改成 `py -3` |
