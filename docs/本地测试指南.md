# G-POT Loc · 本地测试指南（v0.4.x 实测迭代版）

> 本指南给你一份「双击就能测」的版本。**业务逻辑已是真实内核（M2 迁移完成）**：
> 真识别引擎、真提取、真落盘、真启动游戏——可以直接拿真实游戏走全流程。

---

## 一、这是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 七步流水线的完整可交互 UI（无边框窗口，无黑窗） | 打包成单 exe 的发布版（M4 待做） |
| 真实引擎识别（15 类启发式，Starmaker 实测 Unity Mono 0.793） | 全引擎真机验证（15 类中仅部分真机测过） |
| 真实提取（真扫游戏资源 + 护栏统计） | 完整类型树解析（约 1,000 条长对话缺口仍在，如实展示） |
| 真实翻译（8 后端 + batch_fast 批量对齐） | 强制翻译（FR-49：提取后可直接保存） |
| 真实落盘（词典原子写 / RPG Maker 白名单回写 + 备份） | — |

真实逻辑在 `src/gpot/core/`，与前端的契约见 `src/gpot/api/server.py`。

## 二、环境要求

- **Windows 10 / 11**
  - 「窗口版」需系统自带 WebView2 运行时（Win10/11 通常自带）
  - 「浏览器版」免此要求，用系统默认浏览器即可
- 首次运行 bat 会自动探测本机 Python 并装依赖（仅 `pywebview` 一个）。

## 三、启动（二选一，都双击即可）

仓库根目录已放好两个 bat：

| 文件 | 用途 | 何时用 |
|---|---|---|
| **`启动 G-POT 翻译器.bat`** | 起 WebView2 **无边框窗口**（顶栏三键 + 拖拽） | **推荐首选**，接近成品观感 |
| `启动 G-POT 翻译器(浏览器版).bat` | 起本地服务 + 自动开系统浏览器 | WebView2 有问题时用 |

两个 bat 全程**无黑窗**（v0.4.1 起：GUI 模式检测到控制台即 `CREATE_NO_WINDOW` 无窗重启自身）。
**当前版本号常显在状态栏右下角**——双击后先核对它，能立刻判断跑的是不是新版
（程序对旧版本残留实例会自动换端口另起新版，不复用）。

命令行等价方式：

```bat
cd src
pip install -r requirements.txt
python main.py                 :: WebView2 窗口
python main.py --open-browser  :: 系统浏览器
python main.py --no-gui        :: 只起 API（调试用，保留控制台；浏览器手输 http://127.0.0.1:8731/）
python main.py --port 9000     :: 换端口（默认 8731）
```

## 四、七步走查清单（建议逐条核对）

| 步 | 操作 | 预期表现 |
|---|---|---|
| **0 配置** | 选后端 → 填参数 → 点「测试连接」 | 成功显示实测延迟 + 模型名建议；失败显示具体原因；「保存并继续」解锁后进第 1 步 |
| **1 游戏** | 点「浏览」（现代版对话框）或粘贴路径回车 | 显示游戏名 + 已有条数；含 BepInEx 的目录自动下钻到游戏根 |
| **2 引擎** | 点「识别引擎」→ 部署工具 | 引擎名 / 置信度 / 硬证据 / 管线三连（从哪来→写到哪→怎么生效）；工具包 sha256 校验后部署 |
| **3 提取** | 点「开始扫描」 | 真 扫游戏资源；显示 新增 / 已存在 / 护栏拦截 / 在表总数；完成后第 4、5 步同时解锁 |
| **4 翻译** | 双击任意行译文格 / 搜索 / 筛选 / 翻页 | 双击→输入框→Enter 或失焦**立即落盘**；分页与每页条数（50~500）即时生效；「翻译未译条目」跑真后端 |
| **5 落盘** | 选引擎（默认锁定识别结果）→ 主按钮 | Unity=写词典即生效；RPG Maker=备份后白名单回写；Coming soon=只显示「敬请期待」 |
| **6 验证** | 点「启动游戏验证」/「打开译文目录」 | 真 启动游戏主 exe / 资源管理器定位译文目录；自检三项显示结果 |

## 五、三个最值得你重点看的验证点

1. **导航锁（刚性规则）**：左侧未解锁的步骤是灰色、不可点。已过的步骤能自由回跳，
   未来的步骤点不动——这证明 `core/store.py` 的锁真实生效。提取完成后注意第 4、5 步**同时解锁**（FR-49）。
2. **第 5 步按引擎变脸**（这是界面设计的核心）：
   - **Unity**：显示「游戏本体不动 / 写入词典」，**没有**还原按钮
   - **RPG Maker MV**：显示字段白名单 + 「不翻」黑名单 + **「还原原文」按钮**（会改真实文件）
   - **Coming soon**：页面只有「敬请期待」一行，**没有**伪装入口
   - 切到非当前引擎时保存禁用、徽章字母跟随所选管线、「还原原文」隐藏（FR-48）
3. **双击编辑与分页**：改一个译文 → 立刻去第 5 步保存 → 游戏里能读到——
   这是日常改词的完整动线，不需要重跑提取。

## 六、已知限制（诚实告知，避免误判）

- **长对话缺口**：约 1,000 条长段对话拿不到（类型树被剥离），提取页有明示；需 IL 级 hook，不在本期。
- **无边框窗口暂无边缘拖拽缩放**（pywebview 未内建，后续 Win32 消息补）。
- **未实现**：FR-37 步骤状态跨启动持久化、CSV 导入导出 / 查找替换 / 清理重复按钮（占位）、右键行菜单。
- **无方案引擎**（TyranoScript 等）目前统一显示「Coming soon」；工具包清单只含有可靠 Windows 发布包的引擎。

## 八、常见问题

| 现象 | 解决 |
|---|---|
| 端口被占用（提示地址已用） | 程序会自动换端口；也可 `--port 9000` 手动换 |
| 双击出来的是旧版本 | 看状态栏版本号；关掉旧实例窗口再双击（程序对旧版本实例会自动绕开，不复用） |
| WebView2 窗口空白/报错 | 系统缺运行时，改用「浏览器版」bat |
| 中文乱码 | bat 已处理编码；若仍乱码检查系统区域设置 |
| 启动瞬间有个最小化的东西一闪 | 正常——那是启动器压到任务栏的引导进程，随即自行退出，不会留下窗口 |
