## 0. 美学方向（设计原则 · 已定稿）

> **本说明书的视觉落地以 `src/gpot/ui/assets/` 的 `index.html` + `styles.css` 为准（2026-10-10 定稿）。**
> 演进史：Fluent 浅色靛蓝 → 深夜灶台暖金 → 炼香工坊粉紫（以上三稿均因「AI 模板味/结构未动」被否）
> → **配方台账重绘（2026-10-10 过审）→ 明暗双主题定稿（2026-10-10 拍板）**。视觉层就此关闭探索。

**定位**：Windows 桌面端的独立游戏汉化工作台。三区布局范式保留（老板已拍板），
**拒绝"通用企业模板"观感**——渐变圆角卡堆叠、auto-fit 等宽指标网格、999px 药丸徽章、
每屏同骨架，四套模板配方全部禁用。

**核心意象 · 炼香工坊的配方台账（Alchemical Ledger）**：产品名 **G-POT** 即一口「锅」，
口号 *把生肉熬成蜜语* 是炼制动作。界面不是「发光的魔幻工坊」，而是**工坊里那本认真排印的配方台账**：
暗紫机身（默认）/ 白粉纸面（备选）两种纸张，玫瑰粉是唯一的墨色重点，
细线分区 + 方形铭文 + 等宽数字带，每个数字都有出处。三个词：**安静、可靠、编辑式**。

**四条设计铁律（定稿版）**：
1. **一个重点墨色**：玫瑰粉是全界面唯一强调色，且是**稀缺资源**——一屏只出现在
   **主按钮**与**导航轨当前步**两处，出现第三次即违规；
   紫 `#9B6BF0` 只用于信息/导管/进度，蜜金 `#E8B45A` 只用于「通过/成品」正向语义，
   品红 `#E0577E` 只用于警告+危险（靠形状区分，不靠色相微差）。
2. **台账材质，全平面**：容器零渐变零辉光，圆角一律 3px；卡片=细线台账分区
   （158px 左铭牌 + 右内容非对称网格），指标=数字带，状态=方形铭文（非药丸），
   输入框=内嵌凹槽（`--inset`）。机身有纸张颗粒与暗角，但没有玻璃和光晕。
3. **动效只做状态变化**：页面 `rise` 入场、悬停微反馈、状态栏进度空闲淡出。
   纯装饰的呼吸/脉冲/流光已全部删除——判据：动效必须传达状态，否则删。
4. **字体零联网**：`Georgia`（衬线展示体，编辑式气质）+ `Cascadia Code`（等宽标注：
   铭牌、徽章、数字带）+ `Microsoft YaHei`（正文），不依赖任何 CDN 字体。

**明暗双主题（定稿）**：暗色为默认（无 `data-theme` 属性即暗）；亮色 = 白粉纸面
（`html[data-theme="light"]` 变量块）；标题栏太阳/月亮按钮切换，`localStorage`
键 `gpot-theme` 记忆。主题只换变量值，不换语义——同一动作在两个主题下语义恒定。

**字体/配色/动效的具体取值见 §1.2 视觉令牌表。**

> 注：`ui_theme.py`（旧库 v3.x tkinter 主题）与 WebView2 版视觉自此脱钩，互不约束。

## 3. 技术选型（**已定 C 路线 · 2026-10-09 老板拍板**）

**C 路线 = Python 内核 + WebView2（pywebview 宿主，Fluent 观感），已实施于 `src/gpot/`。**
三层解耦是最高约束：`core/`（纯逻辑，零 UI/HTTP 依赖，唯一真源）↔ `api/`（HTTP 桥，唯一 UI↔内核耦合点，只出口 JSON）↔ `ui/`（pywebview 宿主 + 纯静态前端，只 fetch API）。
换 UI 技术栈（真 WinUI3 壳 / tkinter）都不用动内核。其余路线留档备查：

| 路线 | 真 WinUI 3 | 保现有 Python 资产 | 相对成本 |
|---|---|---|---|
| D tkinter 重排版面 | 否 | 全保 | 最低 |
| **C Python + WebView2（已定）** | 否（观感接近） | 全保 | 低 |
| B C# WinUI 3 壳 + Python 内核 IPC | 是 | 全保 | 中高 |
| A C# 全量重写 | 是 | **全部丢弃** | 最高（不推荐，已否决） |
